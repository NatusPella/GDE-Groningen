# Issues sluiten 21-11

Vervolg op `docs/ISSUES-OPSCHONING-21-11.md` (branch issues-opschoning-21-11): de 105 sluitkandidaten zijn per stuk nagelopen op de branch `issues-sluiten-21-11` (vanaf origin/main). Zonder Electron en zonder draaiend spel: per issue de commits met `git log origin/main --grep "#n"`, de diff, de dekkende test en de laatste agent-comment gelezen. De tests uit die commits zijn lokaal gedraaid (239 bestanden; alle groen behalve `key_literals_test`, zie #1003 en #1064). Voor de three.js-tests is de vendor-cache uit de hoofdmap gebruikt (niet gecommit).

Regel: een issue gaat dicht als de code en een dekkende test op main staan, de laatste comment geen eigen restpunt meldt en het geen bug is die een visuele hertest vraagt. Een bug met alleen pure tests blijft open met `hertest`; een gebouwde wens die door beeld of gehoor beoordeeld moet worden krijgt `wacht-beeld`; een wens met een eigen open punt blijft open zonder label. Epics en issues met `eigenaar` zijn niet aangeraakt.
