- Uitkomst: **1.488 bestanden, 503,2 MB op schijf**; audio 3.565 clips van mp3/wav naar Opus

  `web-dist/` `Compress-Archive` gebruiken, of `zip` uit Git Bash/WSL. De limieten hierboven
  gelden ook voor die zip.
