# FIRE-runs (historisch)

Deze map bevat de runverslagen van de FIRE-sessies van 25 en 26 oktober 2026, toen de repo op
~0.34 stond. Ze zijn **geschiedenis**, geen actuele planning: de `Files created: 0`-regels in de
runverslagen kloppen niet met het werk dat de walkthroughs beschrijven (de generator vulde die
velden niet) en de stand in `../state.yaml` is die van toen.

De actuele waarheid is: de code, de specs in `../standards/` en het bord (GitHub-issues,
constitution 7). Een nieuwe sessie leest deze map alleen om te zien wat er ooit bedacht is; ze
plant niets op basis van deze bestanden.
